# ICL Replications

Два эксперимента о том, как трансформер использует знакомые операции в новых сочетаниях. В каждом ноутбуке можно разобрать один эпизод, получить ответ модели из сохранённых весов и пересчитать графики по данным запусков.

| Ноутбук | Наблюдение в этих запусках |
|---|---|
| [Assign and Add](notebooks/assign-and-add.ipynb) | На удержанных числовых парах и позициях переменных два из трёх сидов достигли точности выше 98%, у третьего — 47,3%. Ноутбук разбирает, где теряется правильное значение операнда. [Протокол и сравнение со статьёй](experiments/assign-add-implementation.md) |
| [Kobayashi](notebooks/kobayashi.ipynb) | На знакомых сочетаниях гиперсеть точнее обычного трансформера во всех трёх парных запусках. На новых сочетаниях она выигрывает в одном и уступает в двух. [Условия реконструкции и метрики](experiments/kobayashi-implementation.md) |

## Пересчитать результаты

Графики и таблицы сохранены в самих ноутбуках. Для первой установки нужен системный Python 3 с venv и pip либо утилита `uv`, а также доступ к сети для загрузки зависимостей. Команда размещает CPython 3.12 и окружение внутри рабочей копии. Команды выполняются из корня репозитория.

```bash
./scripts/setup
./scripts/jupyter-lab
```

Откройте один из двух файлов в `notebooks/`, выберите ядро **ICL replications** и выполните **Run All**. Для работы в VS Code можно выбрать интерпретатор `.venv/bin/python` этого репозитория. При исходном значении `START_TRAINING = False` ноутбуки используют включённые в репозиторий данные девяти обучений. Предсказания по примерам вычисляются на CPU. [Состав данных, контрольные суммы и границы пересчёта](artifacts/README.md)

## Код и новые эксперименты

- [Исходники](src/icl_lab/) — генераторы задач, модели, обучение, оценка и диагностики. [Конфигурации опытов](configs/experiments/) задают параметры данных и обучения.
- [Скрипты](scripts/) связывают ноутбуки с исходниками, загружают результаты и запускают новые серии. Сохранённые серии обучались на Apple MPS в FP32. Для самостоятельного запуска укажите отдельный каталог результатов и выберите устройство. Доступные параметры выводит `./scripts/local-run --help`.
- [Тесты](tests/) проверяют постановки, оценку и восстановление запуска. [Протокол Assign and Add](experiments/assign-add-implementation.md) и [протокол Kobayashi](experiments/kobayashi-implementation.md) указывают первоисточники и отличия реализаций.

Оба ноутбука проверены полным выполнением на CPU в отдельной копии с другим именем каталога на macOS arm64. Установка на Linux отдельно ещё не проверялась.

В исходниках также есть постановка Garg и скрипты её поэтапного обучения. Для нового запуска доступен [конфиг линейной регрессии](configs/experiments/garg.yaml). Продолжение конкретного старого этапа требует его checkpoint, банка данных и журнала. Поставляемые данные относятся к двум статьям из таблицы.
