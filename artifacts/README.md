# Данные для пересчёта ноутбуков

Каталог содержит измерения и веса девяти обучений. После клонирования репозитория оба ноутбука можно пересчитать с `START_TRAINING = False`. Пути к данным считаются от корня репозитория. Все файлы лежат в обычном Git-дереве.

| Ноутбук | Что читает | Что можно пересчитать |
|---|---|---|
| [Assign and Add](../notebooks/assign-and-add.ipynb) | Три запуска в [assign-add-jupyter-20261119](runs/assign-add-jupyter-20261119/), 45,1 МиБ. По два банка, финальные веса и предсказания, 638 сводок и шесть срезов весов на сид. | Пример из данных, ответы модели, финальную точность и сложение с известными операндами. Кривые обучения строятся из сводок по 319 состояниям. [Скрипт вмешательств](../scripts/diagnose-assign-binding.py) позволяет заново получить [парные наблюдения](records/assign-add-binding-20261120.json) и проследить изменение ответов на шагах 1k, 3k, 5k, 10k, 20k и 30k. |
| [Kobayashi](../notebooks/kobayashi.ipynb) | Две модели по три сида в [kobayashi-jupyter-20261119](runs/kobayashi-jupyter-20261119/), 281,9 МиБ. 120 состояний весов, 240 пар «предсказания и сводка», банки и финальные диагностики. | Два ответа на один запрос, ошибки и R² на знакомых и новых сочетаниях для каждого сида и шага. График декодирования строится из сохранённых метрик обученного декодера и контрольных условий. |

[Научные записи серий](records/) содержат результаты и условия сравнений. Для двух последующих опытов Assign and Add включена [запись итогов](records/assign-add-followup-20261120.json). Их исходные веса и отдельный журнал обучения в эту выборку не входят.

Банки, числовые предсказания, веса и диагностические результаты скопированы из научных запусков. В JSON-сводках сохранённых предсказаний указаны переносимые пути из корня репозитория. Для промежуточных шагов Assign and Add включены сводки метрик. В манифестах публикации и записях серий оставлены научные условия, версии и хеши модели и данных. Исходные прогоны выполнялись на MPS/FP32, предсказания по примерам в ноутбуках пересчитываются на CPU.

Чтобы проверить все 2629 входных файлов, выполните из корня репозитория команду

```bash
shasum -a 256 -c artifacts/records/SHA256SUMS
```

Отдельные SHA-256 в научных записях относятся к указанному в них артефакту исходного эксперимента. [Контрольные суммы этой поставки](records/SHA256SUMS) относятся к байтам переносимых файлов.
